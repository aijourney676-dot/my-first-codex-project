# My First Codex Project

A clean, beginner-friendly website created to practice the foundations of web development. This project uses HTML for page structure and CSS for visual design and responsive layout.

## About the website

The homepage introduces my first web project and highlights three steps in the learning journey:

- Build a page with HTML
- Style it with CSS
- Share it online with GitHub Pages

## Project files

- `index.html` - the main webpage content and structure
- `style.css` - the colors, layout, typography, and mobile-friendly styling
- `file1` - an original practice text file kept from the start of the repository

## View the website

Open `index.html` in a web browser to view the page locally.

To publish it online, this repository can be configured with GitHub Pages from the repository settings. Once enabled, the website can be available at:

`https://aijourney676-dot.github.io/my-first-codex-project/`
